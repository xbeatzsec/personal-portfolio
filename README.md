# Cyber Portfolio

Um portfólio profissional com tema cyberpunk, desenvolvido com React e Vite.

## Tecnologias Utilizadas

- React
- TypeScript
- Vite
- Framer Motion
- Tailwind CSS
- Emotion (Styled Components)

## Características

- Design moderno com tema cyberpunk
- Animações suaves e interativas
- Efeito glitch em textos
- Layout responsivo
- Seções para projetos, habilidades e contato
- Formulário de contato estilizado

## Instalação

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/cyber-portfolio.git
```

2. Instale as dependências:
```bash
cd cyber-portfolio
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Abra o navegador em `http://localhost:5173`

## Personalização

Para personalizar o portfólio:

1. Edite os textos e informações em cada componente
2. Modifique as cores no arquivo `src/styles/global.css`
3. Adicione seus próprios projetos na seção Projects
4. Implemente a lógica de envio do formulário de contato
